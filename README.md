# My Little Grocery V7.4 — Refrigerators & Upright Freezers

本版本以 V7.3 为基础，在收银柜台对面的右侧墙边加入 5 台站立式冷藏设备：
- 3 台饮品展示冰箱（DRINKS）
- 2 台站立式冷冻柜（FROZEN）

## 设备细节
- 透明玻璃门、金属门框与长把手
- 内部冷白 LED 灯带与柔和照明
- 4 层空置展示架；不预先放入任何饮料或冷冻商品
- 每台设备有清晰的外壳、内胆、底部散热格栅与顶部标识
- 点击/轻触玻璃门即可开关；门通过铰链做平滑 3D 摆动动画

## 后续补货扩展
冰箱和冷冻柜分别标记为 fridge / freezer 类型，并保留独立设备对象，后续可把库存商品按类别自动放入对应设备的空层架。

## 保留内容
原木店铺结构、天花板轨道灯、V7.3 入口左侧收银柜台、空旷中央走道及 3D 视角拖动/缩放。

使用支持 ES Modules 的现代浏览器打开；Three.js 从 jsDelivr CDN 加载，需要网络连接。
