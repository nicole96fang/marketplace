# 小镇杂货铺 V3 · 精致场景版

本版本以用户认可的游戏美术画面作为店铺场景素材，不重新生成图片。场景背景由参考图裁切而来，交互热区覆盖在货架与收银台区域上。

## 上传
1. 解压 ZIP。
2. 将 `index.html` 和 `assets` 文件夹一起上传到 GitHub 仓库根目录。
3. 替换旧的 `index.html`；确认 `assets/grocery-scene.jpg` 也在仓库的 `assets` 文件夹中。
4. Commit changes，等待 GitHub Pages 部署。
5. 手机浏览器刷新页面；如仍显示旧版本，清除该站点缓存后再打开。

## V3 功能
- 采用已确认的 3D 微缩杂货铺场景美术。
- 货架点击热区：水果、食品、饮料、日用品、面包。
- 收银台点击结账。
- 商品库存、补货、售出、售价编辑。
- 顾客聊天、人物故事、好感度。
- 店铺清洁、每日任务、账本。
- 店长资料设置、自动存档、备份与恢复。

## 说明
目前人物是已批准场景中的美术人物，作为场景的一部分；货架和收银台已具备独立互动逻辑。逐帧人物走动、独立角色换装动画及可拖拽商品陈列属于后续动画/素材分层阶段，不会假装已经完成。
