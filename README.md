# 小镇杂货铺 · My Little Grocery V2

V2 基于 V1 升级，保留原有经营玩法与存档结构。

## V2 新增
- 店内顾客循环走动动画。
- 点击水果蔬菜、面包食品、饮料日用品货架打开互动面板。
- 在货架面板补货。
- 可以逐个商品修改售价。
- 点击收银台区域可触发结账。
- 点击场景地面可让店长巡视移动。

## 上传 GitHub Pages
1. 解压 ZIP。
2. 用里面的 `index.html` 替换 GitHub 仓库根目录的旧 `index.html`。
3. Commit changes，等待 GitHub Pages 自动部署。
4. 浏览器刷新游戏页面。若仍显示旧版本，尝试强制刷新或清除该站点缓存。

## 存档说明
V2 沿用浏览器本地自动存档。升级前建议先在 V1 的「存档」页面下载 JSON 备份。
