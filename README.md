# 小镇杂货铺 V4 重制版

这是完全重制的 V4：**不使用整张背景图片**。店铺由独立 SVG 图层绘制，包括墙面、地板、门窗、木货架、商品包装、冰柜、蔬果摊、面包架、植物和灯光。顾客与店长是独立的分层角色 SVG，并带有 CSS 行走/待机动画。

## 上传
把 `index.html` 上传到 GitHub 仓库根目录，覆盖旧版即可。无需 `assets` 文件夹，无需上传任何背景图。

## 游戏内容
- 20 种商品、库存、批发进货、售价调整、收银、顾客聊天和剧情
- 店铺清洁、每日任务、店长资料、账本、JSON 备份与恢复
- 顾客独立角色循环进店移动、随机购物、库存扣减、营业额增加
- 手机端场景优先布局，底部导航
- 读取 V3 `mlg-v3` 存档；同时保存到 `mlg-v4` 和 `mlg-v3`

## 角色与画风说明
人物采用独立绘制的分层 SVG，包含脸部、头发、衣服、背包、手脚和高光阴影，并以动画呈现走路与待机。它是 2D 矢量绘制的 3D 玩具感风格，不是预渲染的真实 3D 模型或骨骼动画。
