# My Little Grocery V7.3 — Compact Front-Left Checkout

以 V7.2 为基础，将收银柜台重新定位并缩小。

## 收银柜台
- 移到店铺入口左侧，贴近左边墙壁
- 长边沿左墙方向摆放，面向店铺内部
- 长度缩至约 4.45 个场景单位，约为上一版柜台长度的一半
- 奶油白台面、竖向木条立面、暖白隐藏 LED 灯带
- POS 显示屏、刷卡终端、入口端小置物格及小盆栽
- 不再占用店铺中央走道

## 保留
木板墙壁、木地板、木梁屋顶、天花板轨道灯、3D 视角旋转和缩放。
没有新增货架、商品、顾客或经营 UI。

使用支持 ES Modules 的现代浏览器打开；Three.js 从 jsDelivr CDN 加载，需要网络连接。
