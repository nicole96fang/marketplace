# 小镇杂货铺 · My Little Grocery V1

## 部署到 GitHub Pages
1. 解压 ZIP。
2. 将 `index.html` 上传到 GitHub 仓库根目录。
3. 若仓库已有旧版 `index.html`，先下载备份，再用本文件替换。
4. GitHub 仓库进入 Settings → Pages。
5. Build and deployment 选择 Deploy from a branch；Branch 选 main，Folder 选 /(root)，保存。
6. 等待 GitHub Pages 发布后打开网页即可。

## 当前版本
- 3D感手绘风格 Canvas 杂货铺场景（非照片）
- 商品库存、进货、销售、顾客聊天与剧情
- 店长姓名/发色/服装设置
- 清洁、每日任务、营业账本、每日打烊
- localStorage 自动保存、JSON 备份与恢复

## 注意
当前 V1 是可玩的基础版本。店铺场景和 UI 是程序绘制的原创示意美术；下一阶段可以继续细化成更接近参考图的精致 3D 微缩插画，并增加真正的顾客寻路、拖拽摆货和逐件结账动画。
