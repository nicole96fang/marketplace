# 小镇杂货铺 V6 · 3D 基础版

## 上传 GitHub Pages
1. 解压 ZIP。
2. 将 `index.html` 上传到仓库根目录，替换旧版。
3. Commit changes。
4. 等待 GitHub Pages 更新后重新打开网页。

## 注意
- 本版使用 Three.js 从 CDN 加载 3D 引擎，需要网络连接。
- 场景、货架、商品、人物均由实时 3D 几何模型绘制，不使用背景照片。
- 当前包含基础人物走动、顾客路线、商品点击提示、补货、结账、招呼顾客和清洁按钮。
- 这是可玩的第一阶段原型；人物模型和动作是程序化基础模型，后续可继续替换为更精致的专属角色模型、细化动画和经营系统。
- JavaScript 语法检查通过；请在手机浏览器实际测试 WebGL / CDN 可用性。
